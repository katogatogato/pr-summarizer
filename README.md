# pr-summarizer

Auto-generate PR descriptions and review checklists from git diffs.

[![npm version](https://img.shields.io/npm/v/pr-summarizer.svg)](https://www.npmjs.com/package/pr-summarizer)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Node.js >=18](https://img.shields.io/badge/node-%3E%3D18-green.svg)](https://nodejs.org/)
[![GitHub Action](https://img.shields.io/badge/GitHub-Action-blue?logo=github)](https://github.com/features/actions)

## Features

- **`generate`** — Analyze your branch diff and produce a structured PR summary with categorized changes, a files-changed table, and an auto-generated review checklist
- **`post`** — Generate a markdown summary and post it as a PR comment (or create a new PR) via the `gh` CLI
- **`check`** — Run automated quality checks for debug leftovers, TODO/FIXME markers, potential secrets, large files, mixed concerns, missing tests, and weak commit messages
- **Multiple output formats** — Terminal (colorized), Markdown (GitHub-compatible), and JSON
- **GitHub Action** — Use directly in your CI workflows to auto-comment on PRs
- **Heuristic-based** — No external AI/LLM APIs required; all analysis uses local pattern matching

## Installation

```bash
npm install -g pr-summarizer
```

Or use directly with `npx`:

```bash
npx pr-summarizer generate
```

## CLI Usage

### `pr-summarizer generate [path]`

Generate a PR summary from the current branch's diff against the base branch.

```bash
# Basic usage (diffs against main)
pr-summarizer generate

# Specify a different base branch
pr-summarizer generate --base develop

# Output as markdown
pr-summarizer generate --format markdown

# Output as JSON
pr-summarizer generate --format json

# Write to a file
pr-summarizer generate --format markdown --output pr-description.md

# Specify repository path
pr-summarizer generate /path/to/repo
```

**Options:**

| Option | Default | Description |
|--------|---------|-------------|
| `--base <branch>` | `main` | Base branch to diff against |
| `--format <fmt>` | `terminal` | Output format: `terminal`, `markdown`, `json` |
| `--output <file>` | stdout | Write output to file |

### `pr-summarizer post [path]`

Generate a markdown summary and post it as a PR comment. If no PR exists for the current branch, creates one.

```bash
# Post summary to existing PR
pr-summarizer post

# Create a draft PR with the summary
pr-summarizer post --draft

# Specify base branch
pr-summarizer post --base develop
```

**Options:**

| Option | Default | Description |
|--------|---------|-------------|
| `--base <branch>` | `main` | Base branch for the PR |
| `--draft` | `false` | Create as draft PR |

**Requirements:** The `gh` CLI must be installed and authenticated.

---

### `pr-summarizer check [path]`

Analyze the diff for common PR quality issues.

```bash
# Run quality checks
pr-summarizer check

# Output as markdown
pr-summarizer check --format markdown

# Output as JSON
pr-summarizer check --format json
```

**What it checks:**

| Check | Status | Description |
|-------|--------|-------------|
| TODO/FIXME/HACK | ⚠️ Warning | Technical debt markers left in code |
| Debug leftovers | ❌ Fail | `console.log`, `print`, `debugger` statements |
| Large files | ⚠️ Warning | Files with >300 lines changed |
| Mixed concerns | ⚠️ Warning | Frontend + backend changes in same PR |
| Missing tests | ⚠️ Warning | Code changed but no tests updated |
| Potential secrets | ❌ Fail | API keys, passwords, tokens in code |
| Weak commit messages | ⚠️ Warning | Non-descriptive messages like "fix", "wip" |

**Exit code:** `0` if all checks pass, `1` if any failures.

## GitHub Action

Use `pr-summarizer` as a GitHub Action to automatically generate and post PR summaries in your CI pipeline.

### Example Workflow

```yaml
name: PR Summary

on:
  pull_request:
    types: [opened, synchronize]

permissions:
  pull-requests: write
  contents: read

jobs:
  summarize:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Generate PR Summary
        uses: katogatogato/pr-summarizer@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          base-branch: main
          post-comment: 'true'
```

### Action Inputs

| Input | Required | Default | Description |
|-------|----------|---------|-------------|
| `github-token` | Yes | — | GitHub token for API access |
| `base-branch` | No | `main` | Base branch to diff against |
| `post-comment` | No | `true` | Post summary as PR comment |

## How It Works

1. **Diff Collection** — Runs `git diff` and `git log` between your base branch and HEAD
2. **File Categorization** — Classifies changed files by area (API, UI, tests, docs, config, database, security)
3. **Summary Generation** — Produces a human-readable paragraph based on file categories, commit messages, and line counts
4. **Checklist Generation** — Auto-generates review items based on detected patterns (new deps, large files, missing tests, etc.)
5. **Output Formatting** — Renders in your chosen format (terminal, markdown, or JSON)

### File Categorization Patterns

| Category | Path Patterns |
|----------|---------------|
| API Changes | `*/api/*`, `*/routes/*`, `*/controllers/*`, `*.router.*` |
| UI Changes | `*/components/*`, `*.tsx`, `*.vue`, `*.css`, `*.scss` |
| Tests | `*.test.*`, `*.spec.*`, `*/__tests__/*` |
| Documentation | `*.md`, `*/docs/*` |
| Configuration | `package.json`, `*.config.*`, `*.yml`, `Dockerfile` |
| Database | `*/migrations/*`, `*.sql`, `*/prisma/*` |
| Security | `*/auth/*`, `*/middleware/auth*` |
